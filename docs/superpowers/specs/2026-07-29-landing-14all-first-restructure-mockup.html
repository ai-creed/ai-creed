how it works

three moves, one window.

01

fan out

hand one task to three agents — or three tasks to three agents. each runs in its own git worktree: own branch, own terminal, no collisions.

02

stay oriented

the sidebar is mission control: working · quiet, ready · tests passed, waiting · needs a decision. glance, don't babysit.

03

review inline

highlight a line in the diff, leave a comment — the agent picks it up and fixes in place. no PR round-trip, no copy-paste.
